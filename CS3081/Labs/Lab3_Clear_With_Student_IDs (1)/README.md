## How to run

Install Python 3 and run these commands in this folder:

```bash
pip install termcolor
python harry.py
python clue.py
python puzzle.py
python knights.py
```

`knights.py` prints the results for Puzzles 0, 1, and 2. The PDF has our explanations, truth table, and output captures. Bonus Puzzle 3 is not included.
