# Abubaker Baobaid — Portfolio

A static personal portfolio made with HTML, CSS, and JavaScript. No build step or package installation is needed.

## Preview locally

Open `index.html` in a browser or use **Open with Live Server** in VS Code.

## Customize before publishing

- Edit the introduction, descriptions, and projects in `index.html`.
- Replace the GitHub URL if your actual username differs.
- The three project cards link to public GitHub repositories visible in the supplied screenshot. Review the descriptions as the projects evolve.
- Your LinkedIn profile URL is already included in the contact section.
- If desired, add a portrait to `images/` and place it in the hero section.
- Adjust colors in the `:root` variables at the start of `css/style.css`.

## Publish with GitHub Pages

Create a public repository named `YOUR_USERNAME.github.io` and upload the contents of this folder to its root. In repository **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`. Your website will appear at `https://YOUR_USERNAME.github.io/` after deployment. Do not paste the URL into Terminal; open it in your browser.

The animations honor the visitor’s reduced-motion preference. All project illustrations are CSS shapes; no image assets or external icon library are required. Google Fonts will fall back to system fonts if unavailable.
